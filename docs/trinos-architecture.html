09 · System Constraints
📌

Platform, Organizational & Data Constraints

🖥️ Platform Constraints
  • Web-based only — mobile app out of scope (current phase)
  • No plugins required — standard browsers only
  • Approved technology stack only
  • Chrome, Firefox, Safari, Edge latest versions
🏢 Organizational Constraints
  • No self-registration — admin provisioned accounts only
  • Super Admin limited to CEO, CTO, CSO or equivalent
  • Team structures mirror actual org hierarchy
  • Routing logic non-configurable per user — follows role
💾 Data Constraints
  • Secure, compliant database environment required
  • 12-month minimum report data retention
  • Deleted users — historical data kept anonymized
  • Personal data handling per applicable regulations
